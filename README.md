# 🌸 Image Slider Project

An interactive Image Slider built using **HTML, CSS, and JavaScript**. 🎀 It allows users to navigate through images smoothly using next and previous buttons, creating a simple and engaging browsing experience. ✨

## 💖 Features

- 🖼️ Display multiple images in a slider
- ⬅️ Previous image navigation
- ➡️ Next image navigation
- 🎨 Attractive and simple UI
- ⚡ Interactive functionality using JavaScript
- 📱 User-friendly design

## 🛠️ Tech Stack

- 🌐 HTML5
- 🎨 CSS3
- ⚡ JavaScript
